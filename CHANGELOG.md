# Changelog

## 1.0.0 — 2026-09-16

### Français

- Retrait de l’ancien bouton Réinitialiser de la barre 2c ; le bouton × assure le reset de cet espace.

Première version stable publique de **strip**.

- Bouton × près de Produire dans 2a, 2b et 2c : reset indépendant des images, réglages et résultats de chaque espace (y compris la mémoire de strips en 2b).

- Gabarits, import Strip / 2 × 2, strip libre, images séparées et exports.
- Interface bilingue FR/EN, y compris les messages et infobulles dynamiques.
- Centrage vertical du titre dans la barre supérieure.
- Nom public `strip`, fichier `strip.html`, liens vers `favicon/favstrip.png`.
- Suppression des anciens placements inutilisés du sélecteur de langue, commentaires et dictionnaire de traduction lisible.
- Respect des noms personnels lors du changement de langue.
- JSZip embarqué pour les exports hors connexion.
- Noms d’export des gabarits harmonisés et métadonnée 300 dpi du PNG de gabarit.
- En-tête de version, page d’accueil et documentation bilingues du dépôt.

### English

- Removed the old Reset button from the 2c toolbar; the × button resets this workspace.

First public stable release of **strip**.

- × button beside Produce in 2a, 2b and 2c: independently resets images, settings and results in each workspace (including stored strips in 2b).

- Templates, Strip / 2 × 2 import, free strips, separate images and exports.
- French/English interface, including dynamic messages and tooltips.
- Vertically centred title in the top navigation bar.
- Public name `strip`, file `strip.html`, links to `favicon/favstrip.png`.
- Removed unused language-control layouts; documented code and readable translation dictionary.
- Personal preset names preserved when switching language.
- Embedded JSZip for offline exports.
- Consistent template export filenames and 300 dpi metadata in template PNG files.
- Version header, bilingual landing page and repository documentation.
